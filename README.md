# CampusPe-GenAI-Assignment-2
AI API Integration – Generative AI Task

## 📌 Overview
This project demonstrates integration of multiple Generative AI APIs using Python.  
Each API is implemented in a separate Python file that takes user input, sends a request, and displays the response.

---

## 🚀 APIs Used
- OpenAI
- Groq
- Ollama (Local)
- Hugging Face
- Google Gemini
- Cohere
